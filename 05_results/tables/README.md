# Camera-ready tables

Every file here is generated by `../../04_pipeline/generate_camera_ready_tables.py`
and matches the tables printed in the camera-ready paper. Regenerate with:

```bash
python3 ../../04_pipeline/generate_camera_ready_tables.py --check
```

`--check` verifies the generated values against the paper's published numbers and
exits non-zero on any mismatch.

| File | Paper table |
|---|---|
| `table1_main.csv` / `.tex` | Pooled CV, ES, VM-F1, RMEM for the six configurations (Table 1a). |
| `table2_per_llm.csv` / `.tex` | VM-F1 by model (Table 1b). |
| `table2_per_llm_rmem.csv` | RMEM by model — the per-model strict accuracies quoted in the text. |
| `table1_finetuned_baseline.csv` | The fine-tuned Text2Cypher baseline row. |
| `table3_categories.csv` / `.tex` | DKB+Hybrid VM-F1 by category × model. |
| `table_robustness.csv` / `.tex` | Strict and tolerant RMEM for the two key grounding transitions, with clustered 95 % CIs. |
| `table_mcnemar_hybrid_vs_dkb.csv` / `.tex` | Per-model exact McNemar, DKB+Hybrid vs DKB, strict RMEM. |

CV and ES are computed directly from the immutable `../raw/results_full.jsonl`.
VM-F1, RMEM and the statistics are read from `../camera_ready/`.

The review-era tables, which used the legacy metric name `SE` and
Stouffer-combined p-values, are superseded and are not part of this release.
